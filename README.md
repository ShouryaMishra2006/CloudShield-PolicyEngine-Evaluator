# CloudShield PolicyEngine Evaluator (Live Implementation)

An enterprise-grade, low-overhead, compile-time type-safe compliance microservice designed to evaluate cloud resource topologies against structured security guardrails in real-time. Built using **Java 17 platform features** and the **Dropwizard microservices framework**, this service functions as an automated deployment gateway to catch structural vulnerabilities (like open administration ports and unencrypted data assets) before they reach cloud production environments.

## Live Cloud Deployment
The service has been containerised via a multi-stage Docker configuration and deployed live onto automated cloud infrastructure backed by a Git-driven CI/CD pipeline.

* **Live Base API URL:** `https://cloudshield-policyengine-evaluator.onrender.com`
* **Live Metadata Resource Pathway:** `https://cloudshield-policyengine-evaluator.onrender.com/v1/evaluator/meta`

*Note on Free Tier Infrastructure: If the service has been inactive for more than 15 minutes, the cloud container will spin down into a sleep state. The very first verification request may take 30–50 seconds to complete while the container executes its warm-up boot phase. Subsequent evaluations will respond in milliseconds.*

## Core Architecture & Modern Java Enhancements

This project serves as a showcase for high-performance, modern Java design principles:
* **Sealed Class Hierarchies:** Utilizes a `sealed interface` for structural domain bounds, providing *Compile-Time Exhaustiveness Checks* inside switch evaluations and eliminating unexpected runtime type subversion.
* **Value-Centric Nominal Records:** Leverage data `record` types to model immutable Data Transfer Objects (DTOs), dropping boilerplate layout overhead while facilitating seamless Jackson JSON data serialization.
* **Pattern Matching with Conditional Guards:** Evaluates complex domain metadata states inside single atomic `switch` blocks using inline conditional operators (`&&`), bypassing slow runtime `if-else` type-casting chains.
* **Defensive Memory Copying:** Intercepts incoming parameters within record compact constructors to perform deep memory copying, neutralizing shallow list mutability security risks.
* **Dropwizard Architecture:** Bundles Jersey (REST routing), Jackson (JSON mapping), and an embedded Jetty servlet container into a highly visible, zero-overhead standalone platform artifact.

```powershell
Invoke-RestMethod -Method GET -Uri "https://cloudshield-policyengine-evaluator.onrender.com/v1/evaluator/meta"
```

## Local Installation & Development

### Prerequisites
* **Java Development Kit (JDK) 17**
* **Apache Maven 3.8+**

### 1. Build the Standalone Package (Fat JAR)
Execute the Maven package phase to trigger code compilation, check preview annotations, and pack dependencies:
```bash
mvn clean package
```

### 2. Launch the Embedded Server Locally
Run the generated binary directly using the native Java runtime, forcing the JVM process to activate preview features from the root tier:
```bash
java --enable-preview -jar target/CloudShield-PolicyEngine-Evaluator-1.0-SNAPSHOT.jar server src/main/resources/config.yml
```
